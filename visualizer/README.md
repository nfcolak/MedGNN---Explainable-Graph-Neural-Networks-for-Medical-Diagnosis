# ProtGNN Patient Graph Visualizer

Interactive dark-themed web interface for intra-patient ProtGNN-style medical graphs.

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Adding Graphs

Place JSON files in `public/graphs/` and register each one in `public/graphs/manifest.json`.
The loader accepts the requested format with `graph_id`, `diagnosis`, `nodes`, and `edges`.
It also supports the older `index`, node `z`, edge `a`/`b`, and edge `kind` fields generated by the existing Python visualization script.

## Exporting The ProtGNN Dataset

From the repository root:

```bash
PYTHONPATH=. python3 visualizer/scripts/export_protgnn_graphs.py
```

This exports the `mimic_intra_patient_disease` PyG dataset into sharded browser-readable JSON under `public/graphs/dataset/` and rewrites `public/graphs/manifest.json`.
The frontend loads the manifest once and fetches only the selected graph shard.
