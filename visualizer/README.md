# ProtGNN Patient Graph Visualizer

Optional, independent dark-themed web viewer for intra-patient ProtGNN-style medical graphs. It is not part of the max6/Top-10 runtime.

## Run

```bash
cd visualizer  # from the repository root
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Explanation Mode

The **Explain** toggle in the toolbar overlays the model's attribution scores on
the graph. Nodes that drove the prediction get a heat halo scaled to their
`importance` value, low-importance nodes are dimmed, and a side panel ranks the
top evidence features with their scores. A patient only shows the overlay when
its nodes carry an `importance` field; otherwise the panel explains that no
attribution was exported for that patient.

The three `★ Explained example` entries pinned to the top of the patient
selector (`graph_17`, `graph_286`, `graph_1258`) carry real attribution scores
and are the quickest way to see the overlay in action. The bulk dataset shards
do not include attribution yet, so add an
`importance` field per node to light up Explanation mode across more patients.

## Adding Graphs

Place JSON files in `public/graphs/` and register each one in `public/graphs/manifest.json`.
The loader accepts the requested format with `graph_id`, `diagnosis`, `nodes`, and `edges`.
It also supports the older `index`, node `z`, edge `a`/`b`, and edge `kind` fields generated by the existing Python visualization script.

## Exporting graphs

The legacy ProtGNN exporter (`scripts/export_protgnn_graphs.py`) was retired
together with the native 30-class code and is not a current supported export
command; its source is recoverable from the Git refs and archives in
[docs/max6-top10-cleanup.md](../docs/max6-top10-cleanup.md). The viewer only
displays graph JSON that already exists. No viewer for CEI graphs is built or
claimed.

### Local-only exports (do not commit)

`public/graphs/dataset/` and the full manifest are local-only exports and are gitignored, because they contain MIMIC subject identifiers. The tracked `manifest.json` lists only the 3 explained examples (`graph_17`, `graph_286`, `graph_1258`). Any export rewrites `manifest.json` with subject_ids, so do not commit the manifest after an export (restore it with `git checkout visualizer/public/graphs/manifest.json`).
